# Security and privacy

## Do not post voice data

Voice recordings, generated narration, private scripts, API keys, and personal
paths are sensitive. Do not include them in public issues, pull requests, logs,
or screenshots.

If a bug requires an audio sample, reproduce it with synthetic tones or a short
non-sensitive clip.

## Reporting a vulnerability

Use GitHub's private security advisory feature for this repository. Do not open
a public issue containing credentials, private audio, or an exploitable payload.

## Scope

This repository contains orchestration scripts only. It does not ship IndexTTS
weights. Vulnerabilities in IndexTTS, PyTorch, Gradio, or model files should be
reported to their upstream projects.
